## ⚡ Hướng Dẫn Sao Chép Vào Notion Trong 1 Bước

1. Mở trang Notion của bạn.
2. Mở file Markdown tương ứng (ví dụ: `01_bang_dieu_khien.md`).
3. Nhấn `Ctrl + A` (chọn tất cả) -> `Ctrl + C` (sao chép).
4. Nhấn `Ctrl + V` vào trang Notion. Toàn bộ Heading, Bảng, Callout, Tip và Danh sách sẽ tự động giữ nguyên cấu trúc.
5. Kéo thả file ảnh tương ứng trong thư mục `docs/user-guide/images/` vào khối hình ảnh trong Notion.
